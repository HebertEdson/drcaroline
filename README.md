# Site da Dra. Caroline

Site estático para a Dra. Caroline Filgueira Rufino, ginecologista e obstetra. A estrutura, os comportamentos responsivos e os efeitos de movimento foram preservados do projeto `montaigne` e adaptados para a identidade da profissional.

- Instagram: [@dracaroline.ginecologista](https://www.instagram.com/dracaroline.ginecologista/)

Os serviços apresentados são: consulta ginecológica de rotina e prevenção, pré-natal e pós-parto, planejamento reprodutivo, DIU, implante contraceptivo, histeroscopia, preventivo, PCR para HPV, manejo de condições ginecológicas e saúde sexual.

## Visualizar

Abra `index.html` diretamente no navegador ou execute `npm run build` para gerar a cópia de publicação em `dist`.

## Movimento

As entradas com desfoque e deslocamento, a animação de títulos palavra a palavra, o parallax limitado, a navegação responsiva e o botão de pausa de animações foram mantidos. O botão permite interromper os efeitos sem ocultar conteúdo.
